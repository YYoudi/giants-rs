## Selector and ownership order

The ordinary pistol secondary now admits the acquired contact branch and logical
state 60. It selects the dedicated contact channel without a model-speed playback
source. Entry requires the acquired contact response bit. Both velocity thresholds
are strict; the lower threshold additionally
requires prior logical state 2. The existing high-descent path precedes this
decision; impact handling also keeps its separate earlier position and refusal.

With prior state 60 and sufficiently negative vertical velocity, the selector can
retain the current channel without any request, even if that channel differs from
the dedicated contact clip or its end flag is set. This is not a forced animation
repair. That hold does not require the contact bit to remain set. Once the hold
condition ends, ordinary acquired selection resumes.

The common effect tail uses the **previous** logical state, not this call's newly
selected state:

| Previous state | Existing owned context | Acquired action |
| --- | --- | --- |
| 60 | None | Prepare the source's named slide effect and retain its identity |
| 60 | Present | Keep the same context without another random draw |
| Other | Present | Release the prepared context and clear the owned link |
| Other | None | No context operation |

Consequently entry need not create an effect immediately, and leaving state 60
can retain the context for one more selector call. The effect label suggests
sliding; the earlier diagnostic called this a contact-landing provider. That label
alone does not establish complete landing, water or collision semantics.

The Session owns a generational context identity separately from the normalized
payload presence word. Foreign, missing, stale or inconsistent bindings are
refused. Creation or cleanup and the preceding selector writes survive a later
failure; the failed physical cycle cannot replay them. The ordinary channel
setter follows the effect operation, preserving native order.

## Separate declarations, predicates and transport

The world supplies ordered scenario records and a separate mission-slot name
table. Each selected mission supplies actor declarations, objective marks,
slot parameters and cinematic requests. Keep scenario index, menu index, source
ID and slot index distinct. A command8 mark ORs its low nibble into the current
actor's response flags; preserve source order and placement/child identity.

`mission_objectives::Program` currently admits stationary class1017/state94
destinations with proximity marks1/4, plus an explicit collection quota. It
requires producer coverage to match the world's required count. A moving actor's
initial placement cannot substitute for its live pose. Death targets, moving
actors, child ownership and other objective kinds remain unbound.

The PC proximity service consumes a destination once. Mark4 first compares the
actual carried resource with the selected slot's signed quota. Accumulated
collection credit is a different value. Proximity tests include the acquired
near-distance branch and the ten-unit forward point against the current AABB.
Success increments the shared counter, clears only the low mission nibble and
requests the source language notice. Queue acceptance is not HUD display proof.

The prototype PS2 function has a related resource/proximity gate, but uses a
radius-based volume instead of this PC fallback. Preserve that divergence.
The exact cross-platform attribution remains **probable**. A private control
compared 6,000 supplied PC predicate contexts without selected-result differences;
classification, actor storage, bounds, quota, suppression, formatting and text providers were
supplied. It establishes neither native mission initialization nor gameplay.

## Population coverage

Herd admission follows authored declarations rather than a Story2 name test.
Mission declarations must be considered before deciding that a scene has no herd.
An audit found herd declarations in 22 of the 33 loose world files accepted by the
reader. These include Mecc, Delphi, Kabuto and multiplayer worlds. Declaration
counts are not live birth counts, and this is not a census of every archive-only
stream. Story5's first mission adds one marker to its nineteen world markers;
the bound total is twenty. Exact-build graphical entry admits both herds and
generates/draws nineteen living Vimps. This is not full Story5 mission acceptance.
The ordinary live driver still requires its supported controlled-Mecc
owner and real class resources, clocks, markers, areas, audio and retirement
services. Removing the world-name restriction does not enable Delphi, Kabuto or
multiplayer gameplay, or invent missing spawn markers.

Future work must validate each newly admitted population on the installed data
and exact graphical build, retain failed cases, then update the public evidence.
No executable, raw table, extraction, native listing or research input belongs in
the public repository. Symbol availability establishes no redistribution rights.
